# GitHub Repository Explorer

## 1. Project Overview
GitHub Repository Explorer is a Python project that uses the GitHub API to search for public repositories. It retrieves repository information in JSON format and displays useful details such as repository name, owner, programming language, and star count.

## 2. Objectives
- Learn how to work with APIs in Python.
- Retrieve data from GitHub.
- Process JSON responses.
- Explore and filter public repositories.

## 3. Technologies Used
- Python
- Requests library
- GitHub REST API
- JSON

## 4. Features
- Search public GitHub repositories.
- Fetch repository information through API requests.
- Display repository names and owners.
- Show programming languages.
- Display repository star counts.
- Sort repositories by popularity.
- Filter repositories by programming language.
- Handle API and connection errors.

## 5. How to Run
Install the required library:

```bash
pip install requests
```

Run the program:

```bash
python github_explorer.py
```

Enter a repository search query when prompted. An active internet connection is required.

## 6. Output
The program displays matching GitHub repositories with their details and provides sorting and language filtering options.
