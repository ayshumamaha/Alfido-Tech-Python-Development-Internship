# Retail Sales & Product Performance Analyzer

## 1. Project Overview
Retail Sales & Product Performance Analyzer is a Python data analysis project developed as part of a Python internship. It analyzes retail sales information to understand revenue patterns, product performance, category performance, and monthly sales trends.

## 2. Objectives
- Analyze retail sales data.
- Calculate revenue.
- Identify top-performing products.
- Compare product categories.
- Understand monthly sales trends.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## 4. Features
- Automatically generates sample retail sales data.
- Loads and processes CSV data.
- Performs data cleaning.
- Calculates total revenue.
- Analyzes product performance.
- Summarizes category-wise sales.
- Analyzes monthly revenue.
- Generates data visualizations.
- Displays key sales insights.

## 5. How to Run
Install the required libraries:

```bash
pip install pandas numpy matplotlib
```

Run the program:

```bash
python retail_analyzer.py
```

The program generates the sample dataset automatically.

## 6. Output
The program displays sales summaries, revenue analysis, product and category performance, monthly trends, and charts.
