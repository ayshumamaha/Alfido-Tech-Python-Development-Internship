# Student Task & Assignment Tracker

## 1. Project Overview
Student Task & Assignment Tracker is a web-based application developed using Python and Flask as part of a Python internship. It helps students manage assignments, track task completion, edit task details, and organize their academic activities through a simple web interface.

## 2. Objectives
- Develop a basic web application using Flask.
- Manage student assignments and tasks.
- Track completed and pending assignments.
- Implement basic CRUD operations.
- Store task information using JSON.

## 3. Technologies Used
- Python
- Flask
- HTML
- CSS
- Bootstrap
- JSON

## 4. Features
- Web-based task dashboard.
- Add new assignments.
- Edit existing assignments.
- Delete assignments.
- Mark assignments as completed or pending.
- Store assignment data in a JSON file.
- Simple and user-friendly interface.

## 5. How to Run
Install Flask:

```bash
pip install flask
```

Run the application:

```bash
python app.py
```

Open the following URL in your browser:

```text
http://127.0.0.1:5000
```

The application creates its JSON storage file automatically.

## 6. Output
The application displays a dashboard where students can add, update, delete, and track assignments using a browser.
