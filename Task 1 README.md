# Automated Document Organizer

## 1. Project Overview
Automated Document Organizer is a Python programming project developed as part of a Python internship. It organizes files into different folders based on their file extensions, making file management easier and more efficient.

## 2. Objectives
- Automate file organization.
- Identify files based on extensions.
- Create categorized folders automatically.
- Reduce manual file sorting.

## 3. Technologies Used
- Python
- OS module
- Shutil module
- File handling

## 4. Features
- Automatically creates a demo folder.
- Generates sample files for demonstration.
- Categorizes files by extension.
- Creates folders for different file types.
- Moves files to the appropriate folders.
- Prevents overwriting existing files.
- Displays an organization summary.

## 5. How to Run
No external libraries are required.

Run the program:

```bash
python document_organizer.py
```

## 6. Output
The program creates a demo directory with sample files and organizes them into folders such as documents, images, and other file categories.
